# Multi-Platform Task Tracker

A cross-platform task and workflow manager built with Flutter, designed to deliver a cohesive user experience across Web, Desktop, and Mobile interfaces.

## 🚀 Features
- **Cross-Platform UI:** Optimized layouts for web browsers and mobile viewports.
- **State Management:** Reactive state handling for completing, adding, and filtering workflow tasks.
- **Ubuntu Theme Integration:** Uses dark mode UI palettes aligned with open-source desktop ecosystems.

## 🛠️ Tech Stack
- **Framework:** Flutter (Web & Mobile)
- **Language:** Dart
